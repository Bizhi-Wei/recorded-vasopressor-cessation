# 28天结局可观测性审计计划

日期：2026-09-15；在本轮新增28天结局汇总前锁定。不重拟合撤药效应。

1. 分别以470次住院的首次稳定时间和284次住院的实际首次单药停止时间为起点。后者分NE先停192与加压素先停92；两个起点的结果不相加，不把住院数当独立患者数。
2. 死亡窗口为起点后至28天（含截止时点）。重新读取所有相关患者的原始patients和全部admissions。医院deathtime优先；若仅有日期dod，用[当日零点，次日零点)区间判定，跨起点或28天边界保留不确定。检查死亡早于起点、医院死亡多时间值、dod与deathtime日期冲突和死亡后新入院。官方3.1说明支持最后出院后一年内死亡链接；采用最后已知住院出院后365天作为保守覆盖下限。缺少死亡记录且窗口在该范围内仅称“链接记录内未记录死亡”，不称主动随访完整或链接100%敏感。
3. 用原始全部icustays按subject_id查找窗口内本院ICU接触，包括其他hadm_id。新stay_id且intime不早于本次ICU出科时点，才计为随后ICU接触；无法区分计划返科与非计划再入。无此记录不证明未在其他医院再入ICU。
4. 本院ICU/住院占用时间为窗口内各区间取并集，避免重复计时；仅为行政记录占用时长，不是死亡调整后的ICU-free days。检查区间与死亡时点的冲突。窗口固定28天，不因死亡缩短行政记录核查窗口。
5. 从原始inputevents提取窗口相关全部ICU的六种升压药，按现有精确时间线规则归一并重建。只汇总记录中正剂量时长与未知活动剂量时长（取并集），绝不以最后一次停药替代累计用药。无记录按0是现有ICU重建假设，不能外推到ICU外。区间记录不独立验证临床给药真实性。
6. 28天升压药自由天数、机械通气自由天数和广义器官支持自由天数不输出为有效结局。机械通气/RRT/MCS的完整28天时段本轮未重建；旧VFD升压药代理变量不能改名成通气自由天数。本轮不做器官支持效应检验。
7. 产出逐住院可观测性表、本院随后ICU记录、源数据哈希、边界测试、汇总、证据状态表及中文审计报告。新稿以描述性实践为主体；仅将通过审计的28天记录结局作为描述，比较模型保留探索性标签。

依据：MIMIC-IV 3.1 数据说明 https://physionet.org/content/mimiciv/3.1/ （2026-09-15核验），patients、icustays、inputevents官方表文档。外院ICU覆盖没有从上述文档得到保证。
