# 设计可行性复核 v1

本计划在既有比较结果已经产生后制定，属于事后设计诊断。保持全部原队列及效应不变，不新增或挑选RR。

1. 固定1、2、4、6、12小时节点，仅描述原稳定池的首次动作分布，不依据结果优化宽限期。
2. 对284次实际撤药，描述t0前NE/加压素剂量、前2小时稳定条件、距首次稳定时间；核对当前决策时是否仍符合原稳定定义。
3. 记录撤除药在5、15、30、120分钟内是否有重启，并区分在重启前发生死亡、出ICU或未知剂量的不可完全观测情况。短间断不能自动判定为记录错误。此项使用撤药后信息，仅作测量审计，不用于删样本、暴露分类或基线入模。
4. 使用已有PS产生重叠权重：加压素先停为1-PS，NE先停为PS。仅检查ESS、固定未加权标准差分母的平衡、缺失指标和权重集中度，不计算新效应、不重新拟合PS。既有PS为惩罚回归，不能声称重叠权重会实现精确平衡。
5. 重叠权重针对不同于原总体的重叠人群，改善平衡也不能当作原总体因果结论的修复；0.10仅为平衡描述参考线，非充分有效性证明。

产物置于`rebuild_v3/design_feasibility/`。下一阶段建议由上述支持与测量诊断决定；禁止通过删除实际剂量等重要变量使比较看似平衡。
