# 实际撤药时重叠人群分析修订 v1

本修订在已知原IPTW、CCW及重叠权重平衡诊断后制定，明确属于事后分析。以下内容在计算新重叠权重效应前固定；不称预注册或独立验证。

## 目标和人群

目标为实际首次单药撤药决策时，观察到两种撤药顺序均有一定可能性的重叠人群中，顺序与后续本次ICU内结局的校正关联。保留原284次实际撤药为主场景；第二场景仅限动作前连续两小时仍满足原稳定条件的272次住院（185 NE先停、87加压素先停）。该限制仅用动作前信息，形成不同目标人群；不能把两场景视为相同总体效应。

稳定池、手术定义、时间零点、原始剂量精度、首次动作、结局事件/竞争事件/观测删失规则均沿用核心v3。不使用停药后持续时长选择入组，短暂停顿和重启保留。A=1加压素先停，A=0 NE先停，RR/RD及连续差方向为1相对0。

## 权重和结局

每个场景分别拟合原24协变量加固定缺失指示的惩罚Logistic PS（C=1、最多3000次迭代），中位数插补、标准化各自拟合；不删剂量或调参追求结果。权重A=1用1-PS、A=0用PS，不另截尾。它强调PS接近0.5的人群，不能恢复原总体的ATE；惩罚拟合不保证精确均值平衡。

主结果为实际撤药起算24小时反跳累积发生风险、RR、RD，死亡/转出ICU作为竞争事件，精确时间加权Aalen–Johansen。6和12小时为次要窗口。另分解24小时首发事件：重启、继续药升级、新药、动作同刻升级或新药；其他首发成分也当竞争事件，成分CIF之和必须等于复合CIF。这不是各成分不限顺序的总发生率。

连续探索结局固定为0–6小时NED峰值变化、0–6小时MAP、低于65的读数比例，以及0–6、6–12、12–24小时乳酸。使用可观测记录子集，缺失不补0；报告每臂观测人数、子集ESS和完整窗口数，不解释为全体完整随访生理效应。不多重校正，明确探索性。

## 推断和诊断

固定300次患者聚类bootstrap，两场景使用同一组从284次住院对应患者名单重抽的样本；先抽患者及其全部住院，再应用动作前稳定限制。每次重新拟合插补、标准化和PS；失败逐项保留，不补齐。百分位区间和每次最大绝对SMD、两臂ESS、最高单人权重份额均输出。点估计权重须复现既有重叠权重诊断。

SMD固定使用每个拟合样本内未加权两臂方差均值的平方根作分母；比较所有原协变量及缺失指示。另报告加权经验CDF最大差和方差比，均值平衡不等于分布相同。0.10仅为描述参考，不作为因果有效门槛；不因某次重抽样失衡剔除该次结果。

## 解释和范围

不以区间跨1或0认定等效，不据此提出临床撤药优先顺序。此前滴定状态、未测混杂、记录停药意图、观测删失机制及选择性测量仍有限制。CCW的不可靠解释状态保持不变。28天器官支持、跨库验证和投稿文件不在本轮计算范围。

结果写入独立目录`rebuild_v3/overlap_v1/`，保留输入/代码哈希和原分析文件。方法依据：[Li、Morgan、Zaslavsky重叠权重](https://www.tandfonline.com/doi/full/10.1080/01621459.2016.1260466)；本项目的惩罚拟合及具体结局规则以上述本地修订为准。
