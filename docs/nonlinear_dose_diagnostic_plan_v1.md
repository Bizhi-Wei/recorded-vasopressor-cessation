# 非线性剂量与重叠支持诊断 v1

固定日期：2026-09-15；已知此前IPTW、CCW、重叠效应和诊断，因此属于事后方法学修订。本轮仅使用入组、策略、患者标识、动作前稳定标记和协变量，不读取结局列，不计算任何新RR/RD或结局均值。

## 固定四场景

原284次实际撤药和动作前连续2小时稳定的272次，各比较原线性PS及一个固定非线性扩展PS。保留原24协变量和缺失指示；非线性模型额外加入NE和加压素的三次B样条。先作log1p变换：NE除0.05 mcg/kg/min，加压素除1.2 U/h；固定原单位节点为NE=[0,0.02,0.05,0.10,0.30,1.50]、加压素=[0,0.6,1.2,2.4,3.6,12]。节点是计算基函数的坐标，不是临床用药阈值；结合既有分布选定，不再按本轮结果调整。

SplineTransformer degree=3, include_bias=False, extrapolation='linear'。不使用按样本分位数选择的节点；缺失剂量在每次拟合内以中位数插补后构造基函数，原变量缺失指示保留。全部原始列及新增基函数一起标准化；PS继续使用LogisticRegression(C=1,max_iter=3000)，惩罚强度不搜索。重叠权重A=1用1-PS，A=0用PS，不另截尾。不删除高剂量记录，不以结局、未来停药持续时间或权重决定入组。

## 诊断而非选效应

每个场景报告原始24协变量及缺失指示的固定分母SMD、加权经验CDF最大差、方差比；非线性模型也报告新增基函数SMD。报告两臂ESS、最大单条权重份额、PS分布、加权剂量分位数及高剂量单条对加权剂量总和的贡献。

NE/加压素原始浮点剂量可能有非临床意义的细微抖动，因此并列提供NE按0.005 mcg/kg/min、加压素按0.1 U/h四舍五入后的CDF差，仅用于显示诊断对测量精度的敏感性。拟合、队列和原始诊断不取整。这些舍入宽度不是经验证的临床等效界值。

以同一患者名单固定300次聚类重抽样，两种人群在抽取后分别应用过去稳定限制，四个场景每次重拟合插补、标准化和PS。报告SMD、剂量CDF差、ESS以及四场景配对诊断差分布；不删除失衡的重抽样，不将0.10作为因果有效通过门槛。

原线性点权重应复现此前结果，使用相同种子2026091502并核对全部原线性bootstrap的SMD和ESS。失败完整记录。所有场景保留，不自动以最小SMD场景计算效果。

## 决策边界

若均值改善但分布、权重支持或重抽样稳定性仍不足，本轮结束时不得称可比性修复；应明确收缩为描述性/可识别性研究的建议。若这些诊断有改善，也只代表有继续评估价值，不能证明无未测混杂或开始宣称优先撤药。任何后续效应计算需另行固定估计目标；28天结局、外部数据库和稿件本轮不改。
