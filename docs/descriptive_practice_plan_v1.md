# 撤药实践和滴定过程描述计划

日期：2026-09-15。本计划在既有比较效应及诊断已经产生后固定，属于审计后的研究定位修订。

目标：描述严格手术日期之后稳定联用NE+加压素者的记录撤药时机、动作前剂量轨迹及记录间断；不把分组描述差异解释为策略效应。主体为470次住院稳定池，动作锚定描述仅限12小时内首次单药撤除284次。时间和药物定义沿用核心v3，不改旧队列。

1. 报告稳定池第一次动作四分类（NE、加压素、同时、窗口内无动作记录），将“无动作”分为完整12小时可观测、提前结束观察及未知剂量。无动作不等同于决定不撤药。
2. 固定动作前6–4、4–2、2–0小时三个窗口，另列稳定时点和动作前左极限剂量。按精确分段对NE/加压素作时间加权均值，报告每个窗口有记录时长、未知剂量时长、完整窗口人数。ICU入科前不补零，未知段不补零。
3. 核心轨迹描述用完整动作前2小时窗口，比较窗口首段和末段剂量：变化>10%为净上调、<-10%为净下调，其余为近似持平。初值为0时单列，不把净变化当作全程单调滴定。10%是描述性阈值，不是临床有意义差异界值。列出两药的3×3（必要时其他）组合和各组计数，不检验组间p值。
4. 每次住院先计算窗口内时间加权均值，再跨住院报告中位数和IQR；不把患者记录条数当独立样本。按患者计数与住院计数分列；本阶段不估计不确定性区间、RR/RD或临床优先顺序。
5. 合并已完成的短间断/重启测量检查与权重诊断，明确计算完成、可支持描述、只能探索、尚未完成的证据等级。原IPTW、CCW、重叠比较保持原限制，不因改研究定位而自动变有效。
