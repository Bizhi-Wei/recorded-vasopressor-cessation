# 核心重建后的权重与时间离散复核

日期：2026-09-14。此计划在已知核心v3结果后制定，属于事后方法学敏感性分析，不能称预注册或独立验证。计算以下新场景前固定本文件，保留全部场景，不按显著性选择模型。

## 固定内容

保留v3的470次住院、精确事件/删失时刻、两种策略、12小时宽限期、24小时复合结局、竞争事件、协变量集合、缺失处理、LogisticRegression(C=1)、概率截断[0.005,0.9995]和每臂99%权重截尾。实际撤药284例主分析不改写。结果写入`rebuild_v3/weight_time_audit/`。

## 比较

CCW固定四格：60分钟/15分钟 × 线性时间/分类时间。分类时间使用每个仍处宽限期的区块指示变量，允许末段删失出现突变；除时间项外模型相同。每个新区块协变量从原始缓存重新按区块起点前记录计算，不能把整小时末记录向前填到15分钟起点。已依从者权重保持不变。既定区块内删失处理不变，因此这只是时间步长敏感性，并非精确连续时间因果模型。

在四个场景中报告未加权、原始权重、99%截尾的两臂风险/RR/RD。60分钟线性场景必须复现v3。对所有场景进行同一组300次患者聚类bootstrap，每次重拟合插补、标准化和删失模型；分组抽到多次按重复患者保留克隆独立编号。报告配对场景RD差及其区间，所有失败保留，不补成成功。

## 诊断

- 按臂、区块报告在险数、删失数、删失模型预测均值与实际未删失比例、权重分位数、ESS，特别查看12小时截止区块。此为样本内校准诊断，不称外部模型验证。
- 分开报告人工删失区块和实际结局分析行的极端权重，避免仅被删失行的极值掩盖实际结果影响。
- 核对完成策略后权重固定、每个克隆只终止一次、12小时截止未丢失、不同网格终止事件一致。
- 实际撤药模型报告PS分组分布、共同支持人数、剂量分布和固定未加权标准差分母的SMD。保留v3用各权重下标准差计算的SMD作对照；不通过删除混杂变量改善数字。

## 解释限制

既定检查通过只意味着代码及所列诊断完成；单一数据集的敏感性一致不能证实无未测混杂、正确的观测停药含义或策略优劣。12小时内何时行动的干预版本仍需方法学复核。若改变步长/时间函数导致权重崩溃或效应不稳定，应降低CCW结果解释等级，不能选择最有利场景替换主结果。
