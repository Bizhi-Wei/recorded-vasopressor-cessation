# 撤药顺序核心分析重建方案 v3

本方案于2026-09-14在重建结果计算前写入。它是审计后的分析修订，不是前瞻注册。主目标是修复时间顺序和实现，不按结果筛选定义。结果单独位于`rebuild_v3/`，旧结果不替换。

## 人群和时间零点

成年ICU患者，当前住院具有明确的心脏手术代码。主口径使用ICD9明确开放瓣膜、CABG、开放修补/移植、开放心脏体外循环代码；ICD10使用对应前缀且为Open Approach，CPB专码单列。具体命中码和标签导出核查。因手术只有日期，最早可进入研究的时刻为手术日期次日00:00，并限制于ICU内；仅服务代理及仅同日手术不进入主口径。研究因此主要针对手术日之后仍需联用患者，不能推广到全部即刻术后患者。

稳定状态定义为t0前连续2小时NE与加压素均有有效正剂量记录、NE≤0.10 mcg/kg/min、加压素≤3 U/h。仅阈值比较容许0.1%相对浮点误差，不对实际剂量取整。使用全段边界连续扫描。t0为满足术后条件及完整过去2小时稳定条件的首个时刻，可以与首次停药同刻（依据该时点左极限）。不要求未来2小时生存/留ICU。每次住院取最早符合者，患者可有多次住院，推断按患者聚类。

首次撤药=合并连续输注记录后，NE或加压素首次从正输注变为无记录的时点；短暂停顿也算一次初始撤药尝试，后续重启是结局。无持续停药确认窗，不利用未来时长分组。精确同刻停止两药为同时撤药。记录缺失仍可能误判停药，属于测量局限。存在未知单位/异常剂量的区段不能当作无用药或稳定。

## 两个不同估计目标

1. **实际撤药分析**：上述稳定池中12小时内首次单药撤药者，t0为首次撤药时刻。暴露A=1固定为加压素先停，A=0为NE先停。24小时院内ICU反跳=先停药重启、继续药较撤药前左极限剂量升级至≥max(1.5倍,+0.02 NE或+0.6 U/h加压素)、前6小时无记录的其他升压药启动。出ICU及死亡为竞争事件，研究的是本次ICU内24小时风险，非出ICU后的未知风险。精确时间加权Aalen–Johansen，IPTW调整仅t0前变量；患者bootstrap每次重拟合插补/标准化/PS。报告RR、RD、两组CIF及权重/平衡。
2. **CCW稳定状态策略分析**：同一完整稳定池，每人两克隆；NE先停或加压素先停的初始撤药尝试须在12小时内，其他方面遵循观察到的自然滴定。错误药先停/同时停在动作时人工删失；无动作到12小时精确人工删失；完成动作后不因重启/加量删失。t0固定为初次稳定达成，24小时**升压支持升级或死亡**=总NED较稳定t0左极限≥max(1.5倍,+0.02 mcg/kg/min)，或前6小时没有的其他升压药启动，或实际先停药之后重启，或死亡；转出ICU为竞争事件。停药前升级属于支持升级，不称反跳。该目标与实际撤药后反跳不同，不以两者RR接近判断稳健性。

CCW使用1小时离散区块，按精确事件、人工删失、转出时间确定首个终止事件；同刻优先临床结局/转出，人工删失其次。12小时无动作删失归入第11–12小时区块。每臂分别拟合仍待完成策略者的未人工删失概率，协变量限区块开始前的历史。已完成者不再接受策略删失概率更新，保留既往累计权重。区块内人工删失者不进入该区块的完整结局分母；在删失前已有临床终止事件者保留。按未删失概率倒数累乘，报告未截尾、99%截尾和权重极值；每次患者bootstrap重新拟合删失模型。用加权离散原因别风险累积为24小时CIF。该方法仍依赖1小时离散近似、模型正确性和序贯可交换性；不能把实现断言通过写成因果假设获证。

## 剂量与生理数据

从原始提取行重新生成分段函数，保留浮点精度；同刻重叠行选开始时间最新者，同开始时间取最大速率，作为可审计记录解析规则。NE/EPI/PHE/DOPA统一为mcg/kg/min，加压素统一U/h，血管紧张素II统一mcg/kg/min。无效状态、非正时长、无法解释单位、负剂量/超出审计上限分别计数。上限仅用于数据异常标记：NE/EPI 5，PHE 20，DOPA 50 mcg/kg/min，加压素12 U/h，AngII 0.2 mcg/kg/min；异常段保持unknown，并在稳定/结局识别中作为不可观测区段处理，不默认为零。

计算推断前的源语义补正：官方文档确认`statusdescription`是区段结束原因。`Paused`区段的[starttime,endtime)保留为实际输注，在endtime才暂停；`Bolus`不作持续输注。首次构建曾沿用旧流程排除Paused，该中间队列计数已撤回，修正后重新提取新名单。此修改发生在任何新效应估计产生之前。

NE当量使用NE+EPI+0.06×PHE+0.01×DOPA+2.5×加压素(U/min)+2.5×AngII(mcg/kg/min)。这是本项目六药可获得部分，未覆盖所有口服/其他血管收缩药；不能称完整全药NEE。精确分段积分和峰值取代15分钟采样。0–6/12/24小时累计峰值与分段窗口轨迹分别命名，转出/死亡后不补零；连续终点报告实际ICU观察长度和完整窗口人数。

血压/心率用charttime<t，化验用charttime<t且storetime<t；尿量以charttime和storetime均在t前为准。表型为回顾性事件记录，并非已验证的实时决策系统。整次住院出院诊断不作基线合并症；手术类型只用t0之前的手术日期，MCS/RRT只用t0之前开始记录。体重只取t0之前的输注体重记录。中位数插补+缺失指示；每次bootstrap重新拟合。旧缓存不保证覆盖新队列，需要按新名单重新流式提取原始表。

## 验证和范围

验证用人工构造边界病例及真实队列断言：未来记录不得改变t0或过去协变量；晚发生手术不得提前入组；短暂停药重启纳入；12小时精确删失可被模型识别；临床事件前后风险集正确；不计观测终止后事件；NEE保留0.03 EPI且捕捉短峰；策略编码从训练到预测一致；实际撤药队列是稳定池子集且动作不早于稳定t0。

重建本轮覆盖MIMIC核心队列、24小时结局、精确NED、实际撤药模型和CCW。不把旧的28天无用药近似值、三库比较、阴性对照或旧稿自动升级为有效。全项目投稿状态在配套分析和稿件全部更新之前保持不可投稿。
